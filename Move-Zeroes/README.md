# 283. Move Zeroes

## Problem

Given an integer array `nums`, move all `0`'s to the end of the array while maintaining the **relative order** of the non-zero elements.

You must modify the array **in-place** without making a copy of the array.

## Examples

### Example 1

**Input:**

```text
nums = [0,1,0,3,12]
```

**Output:**

```text
[1,3,12,0,0]
```

### Example 2

**Input:**

```text
nums = [0]
```

**Output:**

```text
[0]
```

## Constraints

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
